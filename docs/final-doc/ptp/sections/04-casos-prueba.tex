\section{Casos de prueba}
\textbf{Propósito:} Desarrollar los casos de pruebas funcionales y no funcionales para el proyecto.

\textbf{Contenido:}
\begin{itemize}
  \item Diseñe al menos 5 casos de pruebas para funcionalidades clave de su software.
  \item No incluir CRUDs, seguridad o ayuda.
  \item Muestre un ejemplo de un caso de prueba. Los demás pueden estar en un anexo.
  \item Diseñe al menos una prueba para un atributo de calidad.
  \item Puede utilizar la plantilla de la Figura~\ref{fig:plantilla-casos-prueba} para los casos de prueba u otra similar.
\end{itemize}
